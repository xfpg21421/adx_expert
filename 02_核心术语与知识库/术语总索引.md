## 二、收录规范

### 2.1 什么样的词该收录

收录：
- 行业黑话、缩写、协议字段名、指标名、平台产品名（通用化的，如 Performance Max）
- 中文里有多种译法、容易混淆的词
- 英文材料高频但中文材料稀缺的词（**优先级最高**）

不收录：
- 通用技术词（HTTP、JSON、Kafka）——除非在广告语境下含义特殊
- 某公司内部的私有叫法（收录时须注明"XX 公司内部叫法"）
- 一次性出现的营销概念

### 2.2 每条术语的最小信息量

| 字段 | 必需 | 说明 |
|---|---|---|
| 中文名 | ✅ | 多个译法都列出，标明主流叫法 |
| English Original | ✅ | 完整英文 + 缩写 |
| 分类 | ✅ | 8 大分类之一 |
| 一句话定义 | ✅ | 准确、不掺比喻 |
| 通俗解释 | ✅ | 行业里人话怎么说 / 比方 |
| 易混提示 | ⭕ | 有易混词时必填 |
| 出处 | ⭕ | 来自标准/平台政策时必填 |
| 可信度 | ⭕ | `[标准]` `[政策]` `[惯例]` `[推断]` |
| 详见 | ⭕ | 指向深入讲解的文档路径 |

### 2.3 卡片格式

- **速查表行**（放本文件 §四、分类文档表格、中英对照速查表）→ 用 `术语卡片模板.md` §一
- **完整卡片**（放分类详解文档）→ 用 `术语卡片模板.md` §二（12 段）
- **易混对照卡**（多词辨析）→ 用 `术语卡片模板.md` §三

## 五、维护流程

```
1. 研究中出现新术语 → 助手给出「术语三件套」并提示收录
2. 我确认收录 → 追加到本文件 §四 速查表（先占位 [ ]）
3. 展开完整卡片 → 写入对应分类文档，本文件状态改 [x] 并加链接
4. 属于易混组 → 同时补 §三 的对照卡索引
5. 每月扫一遍 §四，把高频但仍为 [ ] 的术语优先展开
```

**同步要求**：新增/修改术语时，检查以下三处是否需要同步：
- 本文件 §四 速查表
- `../README.md` §五 关键术语索引（仅高频 60 词）
- `中英对照速查表.md`（建成后的 A→Z 全量表）
