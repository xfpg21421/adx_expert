## 二、收录规范

### 2.1 什么样的词该收录

收录：
- 行业黑话、缩写、协议字段名、指标名、平台产品名（通用化的，如 Performance Max）
- 中文里有多种译法、容易混淆的词
- 英文材料高频但中文材料稀缺的词（**优先级最高**）

不收录：
- 通用技术词（HTTP、JSON、Kafka）——除非在广告语境下含义特殊
- 某公司内部的私有叫法（收录时须注明"XX 公司内部叫法"）
- 一次性出现的营销概念

### 2.2 每条术语的最小信息量

| 字段 | 必需 | 说明 |
|---|---|---|
| 中文名 | ✅ | 多个译法都列出，标明主流叫法 |
| English Original | ✅ | 完整英文 + 缩写 |
| 分类 | ✅ | 8 大分类之一 |
| 一句话定义 | ✅ | 准确、不掺比喻 |
| 通俗解释 | ✅ | 行业里人话怎么说 / 比方 |
| 易混提示 | ⭕ | 有易混词时必填 |
| 出处 | ⭕ | 来自标准/平台政策时必填 |
| 可信度 | ⭕ | `[标准]` `[政策]` `[惯例]` `[推断]` |
| 详见 | ⭕ | 指向深入讲解的文档路径 |

| 站点声誉滥用 | Site Reputation Abuse（寄生 SEO） | 合规法务 | 第三方内容借用宿主站排名信号发布而宿主缺乏监督，2024-05 起执法 | [x] `09/Niche站与内容站变现.md` §4.3 |
| 经验-专业-权威-可信 | E-E-A-T | 合规法务 | Google 质量评估四维；2022-12 新增 Experience，一手实测权重上升 | [x] `09/Niche站与内容站变现.md` §3.2 |
