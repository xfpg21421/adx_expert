# 10_广告套利Arbitrage

> **本目录用途**：**海外重点专题**。研究"低价买流量、高价卖出转化或展示收益"的差价生意。
> 本目录同时是理解**流量质量、平台风控、变现效率**的最佳切入点——套利者的边际行为最能暴露系统漏洞。

**在全局中的位置**：玩法层第二块，与 `09_联盟营销Affiliate` 共用同一套漏斗与追踪技术，
区别在于收入来源（联盟佣金 vs 广告展示收入 vs Offer 派款）。向上依赖 `08_海外广告生态` 的流量定价认知，
向下直接对抗 `13_反作弊与流量质量` 的检测体系。

---

## ⚠️ 立场与红线（先读这段）

本目录的研究立场是 **认知与防守**，不是操作指南：

| 研究什么（做） | 不研究什么（不做） |
|---|---|
| 套利为什么存在、赚的是谁的差价 | 建站/建号教程、模板包 |
| 完整链路与资金流、单位经济与毛利结构 | Cloaker 的配置与使用方法 |
| 平台如何识别、封禁的信号与逻辑 | 规避审核、绕过风控的技巧 |
| 风险量级、行业周期、可持续性判断 | 推荐具体流量源、工具、Offer |
| 防守方（平台/媒体/广告主）如何减少被套利 | 任何可被直接执行的作弊方案 |

**判定标准**：输出内容如果被套利方直接拿去执行，就是越线。越线时明确拒绝并说明可以改讲什么。

## 写作要点

### 1. 所有流派用同一个分析框架（5 问）

```
① 买什么流量？      源、单价、质量、可规模化程度
② 卖什么收益？      展示收入 / 联盟佣金 / Offer 派款 / 自建产品
③ 差价从哪来？      信息差 / 定价机制差 / 流量质量误判 / 平台补贴
④ 毛利结构？        单位经济公式 + 敏感性 + 盈亏平衡点
⑤ 为什么会被消灭？  平台风控升级 / 竞争抬价 / 政策变化 / 流量质量衰减
```

第 ⑤ 问最容易被忽略，但它是判断"这个玩法还能活多久"的唯一依据。

### 2. 毛利模型必须给公式与敏感性，不给假精确数字

```
日毛利 = UV × RPM_变现 / 1000 − UV × CPC_买量 − 固定成本

盈亏平衡：RPM_变现 / 1000 = CPC_买量
        → 所需落地页 RPM ≥ CPC × 1000
        → 若靠点击变现：所需 CTR ≥ CPC / (单次点击价值)

敏感性：CPC 上涨 10% → 毛利下降 ___%（哪个变量最脆弱）
```

所有具体数值标 `[推断]` 并给**区间**，说明区间来自什么假设。

### 3. 必须区分三种"套利"（易混）

| | 买方套利 | 卖方套利 | 联盟套利 |
|---|---|---|---|
| 谁在做 | Media Buyer | 媒体 / Publisher | Affiliate |
| 差价来源 | 买量成本 < 转化收益 | 多 SSP 竞价抬价 | 买量成本 < 佣金 |
| 典型形态 | Native → AdSense / Offer | Prebid / Reselling | FB 买量 → CPA Offer |
| 主要风险 | 平台封号、素材衰减 | 供应链被 SPO 剔除 | 商家扣量、Offer 下架 |
| 详见文档 | 信息流套利 / 搜索套利 | Prebid与HeaderBidding套利 | 联盟套利漏斗 |

### 4. 防守方视角是必写章节

每篇流派文档结尾都要有一节「**如果你是平台/媒体，怎么防**」：
识别信号（流量特征、行为特征、供应链特征）、可采取的机制设计（底价动态化、供应链透明度要求、
Reseller 白名单、结算延迟与审计权）。这一节让研究有正向价值，也是与红线要求自洽的写法。

### 5. 行业周期与时效

套利玩法半衰期通常 6~24 个月。每篇文档结尾标注：
`> 玩法状态：活跃 / 收缩 / 已消亡（判断时点：YYYY-MM，依据：___）`
并列入 [`../00_研究方法与协作规范/研究进度看板.md`](../00_研究方法与协作规范/研究进度看板.md) §六 失效复核清单。
