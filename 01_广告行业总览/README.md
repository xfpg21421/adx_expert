## 写作要点

- 必须有**产业链全景图**（Mermaid flowchart），且图上标出**资金流方向**。
- 角色图谱每个角色都要写清「收入来源」与「核心诉求」——只写"是干什么的"没有分析价值。
- 市场规模数字**全部标来源与时点**（`> 数据时点：YYYY-MM，来源：xxx`），不同机构口径差异极大，要说明用的是哪套。
- 发展史不要写成编年流水账，要写成"**每个阶段解决了上一阶段的什么问题、又制造了什么新问题**"。
