# 04_产品形态与广告样式

> **本目录用途**：回答**"用户看到什么"**。同样的技术链路，产品形态不同则指标口径、创意规范、变现效率完全不同。

**在全局中的位置**：连接业务与技术的中间层。业务方谈的是样式与位置，技术方谈的是协议与字段，本目录负责把两边对上。

## 写作要点

- 每种样式统一按 **7 个维度**写，便于横向对比：

| 维度 | 内容 |
|---|---|
| 展示位置 | 在页面/App 的哪里，与其他内容的关系 |
| 触发时机 | 什么条件下出现（加载/滚动/点击/退出/完成动作） |
| 尺寸规范 | IAB 标准或平台规范，Web 与 App 差异 |
| 计费方式 | 主流计费与排序公式（CPM/CPC/oCPX/CPV） |
| 典型量级 | CTR / eCPM / 完播率的行业区间（标来源与时点） |
| 体验代价 | 对用户留存、页面性能、内容消费的负面影响 |
| 适用行业 | 哪些广告主/媒体用它效果最好，为什么 |

- 截图与素材放 `创意样例归档/`，文档内用相对路径引用；涉及第三方创意的注明来源。
- **国内 vs 海外**：同一样式在两边的形态差异往往很大（如激励视频在国内游戏化更重、海外更多出现在工具类 App），必须并列写。
