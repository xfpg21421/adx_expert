# 06_定向数据与算法

> **本目录用途**：回答**"广告给谁看"**。定向能力决定了流量的可售卖粒度，也是隐私合规冲击最直接的领域。

**在全局中的位置**：技术主干的第一个专项深化。上游是 `05` 的检索与预估链路，下游影响 `07` 的身份追踪与 `08` 的合规约束。

## 写作要点

- 必须区分两条技术路线，并写清隐私法规如何逼行业从路线 A 转向路线 B：

| 路线 | 依赖 | 精度 | 合规风险 | 现状 |
|---|---|---|---|---|
| A. 基于身份的定向 | Cookie / IDFA / ID Graph | 高 | 高 | 收缩中 |
| B. 基于上下文的定向 | 页面内容 / 语义 / 一方数据 | 中 | 低 | 复兴中 |

- 讲 Lookalike 要给**扩量比例 vs 效果衰减**的量化关系，不要只说"能扩量"。
- 讲 ID Solution 要标清**各方案的采纳率与存活状态**（很多方案已死或边缘化），并标 `[政策]` + 时点。
- 与推荐系统的对照：广告的定向是"**广告主主动约束候选集**"，推荐的兴趣建模是"**系统推断用户偏好**"，方向相反——这个区别要在 `冷启动与探索利用.md` 里讲透。
