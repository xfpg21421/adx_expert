# 14_国内市场与生态

> **本目录用途**：国内市场的**对照系**。覆盖国内平台矩阵、联盟与变现生态、ID 体系、广告法与个保法合规、
> 直播电商广告，以及与海外的系统性 diff。

**在全局中的位置**：本目录的作用非常明确——**防止用海外框架误读国内现象，也防止用国内经验误判海外**。
它不是 `08_海外广告生态` 的附属，而是与之**平行的一套坐标系**：同一维度、同一表格结构、可直接对照阅读。

## 写作要点

- **所有结论与 `08_海外广告生态` 保持可对照的相同表格维度**，便于直接 diff。新增维度时两边同步加，不要一边有列一边没列：

| 统一对照维度 | 海外（→ `08`） | 国内（本目录） |
|---|---|---|
| 市场结构与集中度 | 围墙花园 + Open Web 双轨 | 超级 App 闭环，Open Web 极弱 |
| 交易机制 | RTB / HB / PMP 成熟 | 以平台直投 + oCPX 为主，RTB 份额小 |
| 身份体系 | Cookie（收缩中）/ IDFA / GAID | OAID / CAID（争议）/ 手机号 / 一方 ID |
| 隐私合规 | GDPR / CCPA / TCF | 广告法 / 个保法 / 数安法 / 网安法 |
| 变现工具链 | Prebid.js、MAX、AdMob | 穿山甲、优量汇、GroMore、TopOn |
| Affiliate 成熟度 | 独立生态、网络众多 | 弱，多依附平台联盟（淘宝客 / 京东联盟） |
| 数据透明度 | 第三方验证与 MRC 标准 | 平台自报为主，第三方验证缺位 |

- **不用海外概念硬套国内**：例如把"直通车"直接等同于"Search Ads"、把"淘宝客"等同于"Affiliate Network"，
  都会丢掉关键机制差异（计费口径、流量来源、结算主体）。每处类比都要写明**哪里像、哪里不像**。
- 反过来也成立：国内从业者容易低估 Open Web 程序化的供应链复杂度（Reseller / ads.txt / SPO），这类"国内没有所以不重要"的判断要显式纠正。
- 合规部分只写**条款约束与业务影响**，不构成法律意见；引用的条款标版本号与生效日期，处罚案例标来源。
- 市场份额、广告收入等数字全部标**来源 + 时点 + 口径**（是否含电商站内广告差异极大），推算值标 `[推断]` 并给区间。
