# 术语卡片模板

> 沉淀到 `02_核心术语与知识库/` 下的分类术语表时使用。
> 一个术语一张卡；速查表用「精简版」，深度文档用「完整版」。

---

## 一、精简版（用于术语总索引 / 速查表的表格行）

```markdown
| 术语中文 | English Original（缩写） | 分类 | 一句话通俗解释 | 易混 | 详见 |
|---|---|---|---|---|---|
| 头部竞价 | Header Bidding (HB) | 变现/技术 | 媒体在调 Ad Server 前先让多家 SSP 同时竞价，谁高谁上 | ≠ RTB（RTB 是 ADX 内部竞价） | 12_流量变现与商业化/Header-Bidding与Prebid.md |
```

分类取值（固定 8 类，不要自创）：

`角色平台` `交易计费` `效果指标` `技术协议` `身份隐私` `归因` `联盟套利` `合规法务`

## 三、易混术语对照卡（高频混淆专用）

有些 confusion 不是单个术语能解释的，用对照卡：

```markdown
## 辨析：eCPM vs CPM vs RPM vs ARPU

| 维度 | CPM | eCPM | RPM | ARPU |
|---|---|---|---|---|
| 英文 | Cost Per Mille | Effective CPM | Revenue Per Mille | Average Revenue Per User |
| 视角 | 买方成本 | 卖方收益 | 卖方收益（Google 系叫法） | 业务整体 |
| 是否实际发生 | 合约/报价 | 事后算出 | 事后算出 | 事后算出 |
| 分母 | 1000 次曝光 | 1000 次曝光 | 1000 次（曝光/请求/页面，口径不一） | 用户数 |
| 常见误用 | | | | |

**一句话记忆**：CPM 是你**花**的，eCPM/RPM 是你**赚**的，ARPU 是按**人头**算的。
```
