# 提问模板（直接复制填空）

> 用法：挑一个最贴近的模板，填完粘进对话。上下文给得越全，答案越准、返工越少。

---

## 模板 A｜概念型：搞懂一个术语或机制

```
【类型】概念
【术语】<中文或英文，如 Header Bidding / oCPM / SKAdNetwork>
【我目前的理解】<一句话，可以是错的，方便你纠正>
【我为什么问】<在什么场景下遇到的 / 想解决什么判断>
【市场】国内 / 海外（国家：___）
【端】Web / Mobile Web / iOS App / Android App / CTV
【我要的深度】扫盲 / 原理到公式 / 能落地做系统设计

请按协作规则输出：
定义 + 英文原文 + 通俗解释 + 在链路中的位置（图）+ 为什么存在 +
国内 vs 海外差异 + 常见误解 + 相关术语 + 可信度标签 + 落盘建议
```

---

## 模板 B｜现象型：观察到一个业务/数据现象

```
【类型】业务现象
【现象】<具体描述，最好带数字和方向，如 "某国填充率从 78% 掉到 41%">
【时间】<开始时间、持续时长、是突变还是渐变>
【范围】<全量 / 某国家 / 某广告位 / 某平台 / 某版本>
【背景】<产品、变现方式、最近做过什么变更>
【我已排除的】<已经查过不是原因的项>
【数据】
<贴表格 / 指标 / 分组对比>

请按协作规则输出：
现象复述 → 链路定位（哪一环出问题）→ 原因假设表（原因 / 概率 / 验证手段 / 排除条件）
→ 最可能的 2 个及详细验证步骤 → 修复动作 → 落盘建议
```

## 模板 C｜日志型：读懂真实报文或日志

```
【类型】日志分析
【来源】<RTB bid request / bid response / postback / 广告服务器日志 / SDK 日志 / 归因回传>
【协议或平台】<OpenRTB 2.5 / VAST 3.0 / AppsFlyer / Adjust / 自建 / 不确定>
【我想搞清楚】<逐字段含义 / 为什么没出价 / 为什么没归因 / 异常在哪>
【日志原文】
```
<粘贴，敏感字段可打码但请保留字段名和结构>
```

请按协作规则输出：
协议识别与版本判断 → 字段逐项释义表（字段 / 类型 / 含义 / 本次取值 / 是否异常）
→ 异常点清单（按严重度排序）→ 排查顺序 → 相关背景知识补充 → 落盘建议
```

---

## 模板 D｜案例型：拆解一个玩法或竞品

```
【类型】案例拆解
【案例】<网站 / App / 账户 / 公司名 / 链接 / 截图描述>
【我看到的东西】<现象：他们在做什么、赚什么钱、量级估计>
【我的疑问】<商业模式怎么闭环 / 技术怎么实现 / 毛利有多少 / 能不能复制>
【市场】国内 / 海外（国家 / Tier：___）

请按协作规则输出：
案例概述 → 角色与资金流图（谁付钱谁赚钱，抽成多少）→ 产品链路拆解（用户视角全流程）
→ 技术实现推演（用了什么栈，标 [推断]）→ 单位经济与毛利测算（给公式和区间）
→ 风险与可持续性（平台政策 / 合规 / 竞争）→ 可复用与不可复用的部分 → 落盘建议
```

## 模板 E｜对比选型型

```
【类型】对比
【对象】<A> vs <B>（可多个）
【场景】<我要在什么条件下选：流量规模 / 端 / 地区 / 团队能力 / 成本>
【我关心的维度】<收益 / 接入成本 / 时延 / 合规 / 可控性 / 长期风险>
【我的倾向】<已有的假设，方便你反驳>

请按协作规则输出：
结论先行（选哪个 + 前提）→ 多维对比表 → 机制差异详解 → 各自适用场景与不适用场景
→ 切换/共存成本 → 国内外主流选择 → 落盘建议
```

---

## 模板 F｜专题深挖型：一个主题要成体系

```
【类型】专题
【主题】<如 "无 Cookie 时代的广告身份方案" / "Affiliate 追踪全链路">
【目标产出】<一篇长文 / 多篇拆分 / 带图的架构文档>
【已知的部分】<我已经懂什么，不用重复讲>
【重点】<必须讲透的 2~3 个子问题>
【可省略】<不用讲的部分>

请按协作规则输出：
先给专题大纲（含建议拆成哪几篇 md、各自路径）→ 我确认后再逐篇展开
每篇都要：结构完整、术语三件套、有图、有国内外对照、有可信度标签
```

---

## 模板 G｜复盘归因型：一件事的结果怎么算

```
【类型】复盘 / 归因
【目标】<这次投放/改版/实验想达成什么>
【投入】<花了多少钱、多少人力、多长时间>
【结果】<实际数字>
【归因口径】<用的什么模型：Last Click / MTA / 增量实验 / 平台后台数>
【我的疑问】<为什么各渠道数据对不上 / 这笔钱到底有没有效 / 增量在哪>

请按协作规则输出：
口径差异定位（为什么几个数不一样）→ 各归因模型下的结果对比表
→ 真实增量的估算方法与区间 → 结论与下一步预算建议 → 落盘建议
```

## 通用补充信息（任何模板都可以附上）

```
【角色视角】买方（广告主/DSP）/ 卖方（媒体/SSP）/ 平台 / 联盟客 / 套利者
【阶段】调研认知 / 方案设计 / 线上排查 / 复盘归因
【约束】时延 ___ ms / 预算 ___ / 合规要求 ___ / 团队规模 ___
【输出偏好】要表格 / 要图 / 要公式 / 要能直接落盘的完整 md / 先给结论
【是否落盘】仅对话 / 输出后我说"存"再落盘 / 直接写入 ___ 路径
```

## 快速触发词（懒得填模板时）

| 我说 | 你按什么做 |
|---|---|
| `解释 XXX` | 模板 A 全流程 |
| `为什么 XXX` + 数据 | 模板 B |
| `看这段日志` | 模板 C |
| `拆一下这个案例/站/玩法` | 模板 D |
| `A 和 B 有啥区别` | 模板 E |
| `做个专题：XXX` | 模板 F，先给大纲等我确认 |
| `这几个数对不上` | 模板 G |
| `存` / `落盘` | 按上一轮给的【可保存为】路径写入并更新目录 README |
