## 写作要点

- **写成可执行的 SOP 与 Checklist，不写鸡汤**。每条结论都要能回答：具体改哪个设置、改到多少、多久之后看哪个指标判断有效。
  写不出这三点的建议直接删掉。
- **每条建议必须注明适用前提**，没有前提的建议视为无效：

| 前提维度 | 常见取值 | 会反转结论的例子 |
|---|---|---|
| 预算量级 | 日耗 < $100 / $100~1k / $1k~10k / > $10k | 小预算下"细分 AdSet"是反模式，大预算下是必需 |
| 行业与转化深度 | 电商 / 游戏 / App / Lead Gen / 订阅 | Lead Gen 要看 CPL 与后端线索质量，电商看 ROAS |
| 市场 | T1 / T2 / T3、国内 / 海外 | T3 竞价密度低，宽定向更容易起量，但流量质量需单独验 |
| 投放阶段 | 冷启动 / 学习期 / 稳定期 / 衰退期 | 学习期内调价会重置学习，稳定期则应主动压成本 |

- **诊断优先于优化**：任何优化动作先挂到诊断决策树上定位瓶颈环节，避免"效果不好就加预算"这类无效操作。
- 涉及平台算法机制（学习期长度、Advantage+ / PMax 的黑盒逻辑、竞价排名权重）标 `[平台机制]` + 时点，
  并列入 `研究进度看板.md` 的失效复核清单——平台改版极快，半年即可能失效。
- 基准数字（CTR / CVR / CPA / ROAS）只给**区间 + 前提 + 来源**，不给单点值；自有观察标 `[实测]`，推算标 `[推断]`。

## 诊断决策树骨架（写 `投放数据诊断与优化.md` 时展开）

```
量级上不去 ──→ 预算/出价被限流？→ 结构过细？→ 仍在学习期？→ 受众饱和/频次过高？
CPA 高 ─────→ 拆成 CTR × CVR × 客单价：
              ├─ CTR 低   → 素材（前 3 秒 Hook）/ 人群相关性 / 版位
              ├─ CVR 低   → 落地页加载与承接 / Offer 力度 / 转化路径步数
              └─ 两者正常 → 出价方式与竞争环境 / 归因口径失真（转 07 目录）
ROAS 达标但总量小 → 是否已到边际收益递减点 → 扩量前先做增量测试，而不是先看后台
数据对不上 ──→ 归因窗口 / VTC / 去重 / 时区 / 币种（见 07 目录对账方法）
```
