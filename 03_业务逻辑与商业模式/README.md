## 写作要点

- 每个机制必须写清三件事：**谁受益、谁承担风险、为什么会演化成这样**。
- 拍卖与出价部分**要给公式与推导**，不能只写结论。核心公式例：
  ```
  oCPM bid = target_cpa × pCTR × pCVR × 1000
  eCPM     = bid × pCTR × 1000        # CPC 计费转 CPM 排序
  Ad Rank  = bid × Quality Score       # Google 搜索广告
  ```
- 分成比例一律给**区间 + 来源 + 时点**，不给假精确数字；无来源标 `[推断]`。
- 用"**100 元预算追踪法**"贯穿全目录：假设广告主花 100 元，逐环节算剩多少到媒体手里，这是最直观的讲解框架。
