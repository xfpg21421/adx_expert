## 写作要点

- **每篇必须有架构图或时序图**（Mermaid），图上同时标出**数据流**与**时延预算**。
- 关键公式要**写推导过程**，不只给结论。例：
  ```
  预算约束下最优出价（Lagrangian 对偶）：
    max  Σ value_i · x_i          s.t. Σ cost_i · x_i ≤ B
    →    bid_i* = value_i / (1 + λ)
    λ 由预算消耗速度反馈调节（PID）
  ```
- **标清量级**：各环节的候选量（万→千→百→十）、耗时（μs/ms）、系统 QPS。没有量级的架构描述是无效的。
- 协议内容以 **IAB Tech Lab 官方 spec** 为准并注明版本；平台私有扩展单独标注。
- `广告系统与推荐系统的异同.md` 可以结合我的推荐系统背景做对照式讲解——用已知的推荐链路去锚定广告链路的差异点。

## 时延预算参考骨架（写 RTB 相关文档时复用）

```
用户打开页面          T+0
SSP/Ad Server 决策    T+0~10ms
Bid Request 发出      T+10ms
  ├─ 网络传输          ~10-20ms
  ├─ DSP 处理          ~40-70ms   ← 召回/预估/出价/预算校验
  └─ 网络回传          ~10-20ms
DSP 超时线            T+100~120ms（超时即弃权，no-bid）
竞价结算 + Win Notice  T+120~140ms
创意下载与渲染        T+140~500ms
可见曝光上报          T+?（用户滚动到屏内）
```
